About AnitoPlume

AnitoPlume is a real-time Taal Volcano simulator. It is part of Project Anito, a DOST-PCIEERD funded project worked on within DLSU GAME Lab. The AnitoPlume project is made alongside the writing of an undergraduate thesis paper titled "Interactive 3D simulation of Taal Volcano eruption plumes", which can now be read in the Q1 journal titled "Applied Computing and Geosciences". Read here: https://doi.org/10.1016/j.acags.2026.100331

Videos

The AnitoPlume simulator comes with the following features:

  • Display Settings that allows the user to change Taal Volcano according to specific years and to change the plume visualization.
  • Camera Settings to allow the user to freely move around with two modes, Aerial and Orbital.
  • Plume Direction Tracker which lets the user track the wind and plumes with a handy mini-map to view the potentially affected areas.
  • Simulator Input which lets the user control the wind and plume parameters at their disposal.
  • Playback which allows the user to play, pause, reset and speed up the simulation.
  • Profiler that displays information and can help you identify causes of lag.
  • Multiple Vents which lets the user play around with more plumes.
